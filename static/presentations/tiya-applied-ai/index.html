Notes

Using this kit

  • Fonts. The slides use Roboto Slab and Roboto, Georgia Tech's web typefaces. Install both from Google Fonts on the presenting laptop, or PowerPoint will substitute a similar font.
  • Before delivery. Replace the placeholder data rules with TIYA's written AI policy in the workbook, guide, and slides. Fill in "[TIYA contact]" on the closing slides.
  • Printing. Print each day's workbook from its PDF, double-sided. Print the assessment kit for instructors only.
  • Offline. The browser decks work from a laptop without internet, with a fallback font. The PowerPoint files are the safest choice for the room.
