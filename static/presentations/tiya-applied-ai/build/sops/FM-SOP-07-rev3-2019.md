SOP FM-07 — Emergency Work Orders — Rev 3 — Sep 2019

Emergency calls should be taken by the desk and a work order should be put in. After hours the phone goes to whoever is on call, the on-call list is on the board in the shop. The tech should get there as soon as possible. If the tech can't be reached try someone else.

Emergencies are things like leaks, no AC in summer, power out, etc. Use judgment.

The system should be shut down if needed and the area should be made safe. Supervisor needs to know about it. If parts are needed, a request should be submitted through the normal process.

Call the old after-hours line 706-555-0199 if the desk phone is not working (fax 706-555-0198).

When finished the work order is closed out. Keep paperwork in the binder.
