Knowledge check and exit checklist

  1. What makes an agent different from a prompt?

    • A. It uses a better model.
    • B. Standing instructions, its own knowledge, and tools for a defined job.
    • C. It can never be wrong.
    • D. It runs on its own server.

    B.

  2. What starts an agent built in agent builder?

    • A. A new email
    • B. A schedule
    • C. A person asking it something
    • D. Any of the above

    C. Events and schedules need Copilot Studio or Power Automate.

  3. You share your agent. A colleague gets "I can't find that" for a question your SharePoint document answers. The most likely cause?

    • A. The model is broken.
    • B. They don't have access to that document.
    • C. They asked too politely.
    • D. Agents only work for their creator.

    B. Sharing the agent doesn't share its knowledge sources.

  4. What's the strongest protection against an agent revealing personnel information?

    • A. An instruction saying "never reveal personnel information"
    • B. A polite description
    • C. Not putting personnel information in its knowledge
    • D. Telling users not to ask

    C. An instruction is a request; what the agent can't read, it can't leak.

  5. You change your agent's instructions. What next?

    • A. Nothing
    • B. Rerun your test set before re-sharing
    • C. Delete and rebuild it
    • D. Ask Copilot if the change is OK

    B.

  6. Which agent is tier 3?

    • A. A personal agent that formats your meeting notes
    • B. A team SOP Q&A agent
    • C. An agent that drafts responses to the COR
    • D. A personal brainstorming agent

    C. It drafts communication to the government.
